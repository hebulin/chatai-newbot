# Playwright 端到端测试说明

- 目录用途：存放 chatai-newbot 前端浏览器端到端测试，不属于最终用户产物。
- 测试依赖：`@playwright/test` 1.62.1；由 `web/package.json` 和 `web/package-lock.json` 锁定。
- 安装时间：2026-09-04（Asia/Shanghai）。
- 关联任务：建立管理员登录、SSE 聊天、服务端会话保存与刷新恢复，以及后台持久化指标趋势展示的关键链路测试。
- 2026-09-06 更新：使用 Vite 6.4.3 构建生产包后通过 preview 托管；新增真实 Mermaid 普通图/ELK/思维导图和 XLSX 的网络加载时机及下载验证，保持 API 替身隔离。
- 2026-09-07 更新：新增编辑用户消息后在原会话生成回答分页版本的回归，验证不创建分支、上下文请求、上一/下一版本和刷新后的持久化恢复。
- 2026-09-11 更新：新增中英文系统公告回归，验证自定义标题去除首尾空白、无装饰前缀、空白标题国际化回退，以及普通确认、刷新、重新登录与重新发布时的已读标记；可执行 `npm run test:e2e -- --grep 系统公告` 定向验证。
- 2026-09-11 输出配置更新：在系统设置验证全局缺省、模型继承、独立上限、两层不限、清空恢复及刷新；确认模型编辑页已移除输出设置。继续覆盖超过 6000 Token 的显示、保存、刷新和截断原因提示。工具与浏览器均复用既有安装。
- 2026-09-11 中断提示内联化：达到输出/上下文上限或流中断时，终止原因以内联提示展示在同一条回答消息下方（`.msg-notice`），不再追加独立的错误气泡消息；对应用例断言 `.error-bubble` 数量为 0。
- 使用方法：在 `web` 目录执行 `npx playwright install chromium` 安装浏览器，然后执行 `npm run test:e2e`；需要观察浏览器时执行 `npm run test:e2e:headed`。
- 卸载方法：执行 `npm uninstall --save-dev @playwright/test`，并按需删除本目录及 `playwright.config.js`。

- 2026-09-14：新增“上下文大小/输出大小”独立配置、正整数校验、模型覆盖删除、草稿隔离、焦点和刷新保留测试。API 替身补齐 `/api/auth/me`；原生 option 禁用状态直接校验 disabled 属性。

- 2026-09-14 后续修复：验证部分正文后无 finish_reason/[DONE] 而正常 EOF 时保留中断提示、刷新后状态，以及“基于已生成内容继续”闭环。

- 2026-11-02：新增表格顶部工具栏与全屏查看回归，覆盖桌面深色/窄屏浅色、长宽表格滚动、焦点圈定与恢复、Esc 逐层关闭、多表格隔离及 CSV 下载内容；既有 Excel 按需加载用例改用可访问名称定位下载图标。执行 `npm run test:e2e -- --grep '表格顶部工具栏|生产包按图表'` 定向验证。复用既有 Node.js 24.18.0、Playwright 1.62.1 与 Chromium 1234，无安装升级；沙箱内设置 `PLAYWRIGHT_BROWSERS_PATH=C:\Users\HBL\AppData\Local\ms-playwright`，`TEMP/TMP` 指向项目内本次临时目录，以避开系统目录重定向。

- 2026-11-02 后续：新增长内容吸顶回归，以 120 行表格、100 行 HTML/普通代码、长 Mermaid 图验证滚动中工具栏/列标题位置、横向列对齐、全屏表头、复制与 HTML 预览、卡片结束退出，以及分享页站点顶栏避让。可使用 `--grep '长内容工具栏|分享页长表格'` 定向运行；桌面深色与窄屏浅色用例输出表格、HTML、图表截图供视觉核验。Vitest 的 `stickyHeaders.test.js` 覆盖多卡片共用监听及节点卸载后清理观察器和待执行帧。

- 2026-11-02 快速滚动修复：在同一个 JS 任务内连续大幅滚动并立即测量工具栏/可视表头接缝，随后执行真实滚轮事件；确保修复不依赖 rAF 停滚后补位。断言辅助技术仅识别原表格，并检查吸顶代码栏两侧顶角的命中元素，防止圆角露出正文。表头副本与原表格横向同步由 scroll 事件处理，相关断言等待浏览器派发该事件。本轮常规沙箱外测试审批两次超时，实际使用相同生产 dist 和 API 替身离线验证：在沙箱内通过 route.fulfill 读取静态资源，无网络请求；6 项相关用例通过，临时测试适配器完成后删除。
